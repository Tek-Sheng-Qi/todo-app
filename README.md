# Todo App

A clean, minimal todo app built with vanilla JavaScript.

## Features

- Create and manage projects
- Add todos with title, priority, description, due date, due time and notes
- Colour coded priority levels — high, medium, low
- Checklist items per todo
- Filter todos by priority, status and due date
- Inline expand to see todo details
- Toast notifications
- Data persists via localStorage

## Built With

- Vanilla JavaScript (ES6 modules, factory functions)
- Webpack
- date-fns
- Lucide icons
- CSS Grid and Flexbox

## Getting Started

Clone the repo:
\```bash
git clone https://github.com/Tek-Sheng-Qi/todo-app.git
\```

Install dependencies:
\```bash
npm install
\```

Run the dev server:
\```bash
npm start
\```

Build for production:
\```bash
npm run build
\```
